Краткое руководство

Инструмент позволяет собрать исходные данные проекта в формализованном виде, построить финансовый экспресс-прогноз проекта и оценить его инвестиционную привлекательность. Заполните разделы, используя навигацию слева. По окончании нажмите «Рассчитать проект».

Важное примечание

Это не инструмент финансового моделирования. Формируемый расчёт — оценка баланса бизнес-модели доходности и описываемых затрат.

1. Заполнение данных

  • A. Общие данные — название, горизонт планирования (1–10 лет, больше не рекомендуется), регион, даты старта и первой продажи, валюта, остаток ДС на старте.
  • B. Средства производства — оборудование и единовременные инвестиции с датой вложения.
  • E. Продукты и услуги — что продаём: цена, объём в месяц, дата старта продаж, годовой рост спроса. Коэффициенты сезонности (зима/весна/лето/осень) задаются от 0 до 150 % с шагом 10; 100 % = без сезонной поправки.
  • C1. Прямые затраты — переменные затраты на единицу каждого продукта (сырьё, упаковка, доставка).
  • C2. Косвенные затраты — производственные расходы, не зависящие от объёма (аренда, электроэнергия, обслуживание).
  • D. АХР — административные расходы (бухгалтерия, маркетинг, связь, страховки).
  • F. Персонал — оклады, численность, дата найма. Страховые взносы 30% добавляются автоматически.
  • G. Финансирование — структура источников (кредит / собственный капитал / субсидии), ставка по кредиту. Сумма займа рассчитывается автоматически по потребности проекта в деньгах.

2. Подсказки по заполнению

  • Даты выбираются через календарь — допустимы только месяцы внутри горизонта планирования.
  • Поле «Рост %» — годовое индексирование показателя; применяется автоматически каждый год.
  • Все денежные значения вводятся в основной валюте проекта; результаты выводятся в тысячах этой валюты.
  • Изменения сохраняются автоматически — отдельная кнопка «Сохранить» не требуется.

3. Расчёт и результаты

После нажатия «Рассчитать проект» система построит:

  • KPI-карточки: NPV, IRR, PI, срок окупаемости, потребность в финансировании.
  • График ключевых показателей по годам.
  • Детальную таблицу прогноза: выручка, затраты, EBITDA, чистая прибыль, движение денежных средств.

Ставка дисконтирования зафиксирована на уровне 16%.

4. Экспорт в Excel

Кнопка «Экспорт Excel» выгружает многостраничный файл со всеми разделами проекта, прогнозом и показателями — готовый для формирования финансовой модели.

5. Управление данными

  • Скачать файл — сохраняет все данные проекта в файл .json. Удобно для переноса работы с одного устройства на другое (например, с рабочего ПК на домашний): сохраните файл, перенесите его любым способом (флешка, почта, мессенджер, облако) и загрузите на другом устройстве.
  • Загрузить файл — восстанавливает проект из ранее сохранённого .json-файла. Текущие данные при этом заменяются.
  • Демо данные — пример заполнения данными инструмента, заполняет все разделы примером проекта «Вертикальная ферма» (вертикальная городская ферма, 10 лет).
  • Сбросить данные — очищает форму и удаляет сохранённые значения.
  • Все введённые данные хранятся локально в вашем браузере — на сервер не отправляются.

Уведомление

Горизонт планирования — 1 год

Выбран горизонт планирования 1 год. Вам необходим помесячный прогноз проекта, который не доступен в данной версии инструмента. Выбранный период не позволяет сформировать представление об инвестиционной привлекательности проекта.

Рекомендация: увеличить горизонт планирования до 3-х лет.
